B2B Product Catalog with a Multi-Item Quote Builder

I built a responsive catalog and request-for-quote workflow for a building components supplier. Buyers can find products, select the relevant configuration and quantities, collect several products in one quote cart, and send their project requirements in one request. The supplier gets the context needed to respond with a quote.
