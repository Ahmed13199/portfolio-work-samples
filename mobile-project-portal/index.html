Mobile Project Portal for iOS and Android

I built an Expo and React Native app for a client project portal on iOS and Android. It connects to the same Django API as the web portal. Clients can check milestones, open project documents, and access building models from a phone. The app uses existing accounts and project permissions so staff can manage access in one place.
